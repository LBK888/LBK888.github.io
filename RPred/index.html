How the models work 演算法說明

Persistence 持續法 · naive forecast · phone

“The next value equals the last value.” No parameters. It is the baseline: a model is only useful if it beats Persistence, which is exactly what Skill measures.

ŷ(t+h) = y(t)        for every step h = 1 … N

Hard to beat for very noisy or random-walk data; always late on trends and cycles.

Kalman filter 卡爾曼濾波 · local linear trend · phone

Tracks a hidden level and slope. Every reading: predict → compare with the measurement → correct by the Kalman gain K (卡爾曼增益). K balances trust in the model (process noise Q, 過程雜訊) against trust in the sensor (measurement noise R, 量測雜訊). It also reports its uncertainty (the shaded band). A missing reading means “predict only, no correction”, so the band widens.

state x = [level, slope],  F = [[1,1],[0,1]],  H = [1, 0]
Predict:  x⁻ = F·x          P⁻ = F·P·Fᵀ + Q
Update:   K = P⁻Hᵀ / (H·P⁻·Hᵀ + R)
          x = x⁻ + K·(y − H·x⁻)     P = (I − K·H)·P⁻
Forecast: ŷ(t+h) = level + h·slope

Q and R are multipliers of the data's own step size, so they work for °C and ppm alike. Only Q/R changes the line: large Q/R reacts fast but is jumpy; small Q/R is smooth but lags.

Holt's method 雙指數平滑 · damped trend · phone

Splits the series into a level L (水平) and a trend B (趨勢), both updated with exponential weights. α: how fast the level follows new data. β: how fast the trend changes. φ (damping, 阻尼): shrinks the trend for far steps so a 30‑step forecast does not shoot off.

L(t) = α·y(t) + (1−α)·(L(t−1) + φ·B(t−1))
B(t) = β·(L(t) − L(t−1)) + (1−β)·φ·B(t−1)
ŷ(t+h) = L(t) + (φ + φ² + … + φʰ)·B(t)

Echo state network ESN · 回聲狀態網路 · phone

A fixed, random recurrent network — the reservoir (儲備池) — turns recent readings into an “echo” state r(t). Only the linear readout is learned, online, by recursive least squares (RLS, 遞迴最小平方法). Each forecast step h has its own readout that predicts the change y(t+h) − y(t) directly. Light enough for a phone; weak at events it has never seen (try the first pollution spike in the demo).

r(t) = (1−a)·r(t−1) + a·tanh(W·r(t−1) + W_in·[1; u(t)])     u = normalised reading
ŷ(t+h) = y(t) + σ · w_hᵀ·[1; u(t); r(t)]
RLS:  k = P·x / (λ + xᵀ·P·x)
      w_h ← w_h + k·(target_h − w_hᵀ·x)      P ← (P − k·xᵀ·P) / λ

Changes are replayed over the stored history at once, so the chart and accuracy update immediately.

RNN / LSTM 循環神經網路 / 長短期記憶 · server

Trained on the Colab server, as in Module 02: the last 24 readings → 32 hidden units → the next 10 values. The server starts from a model pre-trained on synthetic water-like curves, fine-tunes (微調) it on class data as it arrives, and saves it to Google Drive, so a restarted server does not train from zero.

RNN:   h(t) = tanh(W_x·x(t) + W_h·h(t−1) + b)
LSTM:  gates (閘門) f, i, o;  c(t) = f⊙c(t−1) + i⊙tanh(W_c·[h(t−1); x(t)])
       h(t) = o⊙tanh(c(t))
Out:   [ŷ(t+1) … ŷ(t+10)] = y(t) + s·Linear(h(24))      s = window spread
Train: 80/10/10 time split · Adam · MSE loss · early stopping

Status PRETRAINED = synthetic data only; READY = fine-tuned and better than Persistence on validation data; WEAK = fine-tuned but not better than Persistence. Live Skill above shows how it does right now.

Chronos‑2 time-series foundation model, 時間序列基礎模型 · server

A transformer pre-trained by Amazon on many time series and used zero-shot (零樣本): it never trains on class data. It reads up to 512 past values and returns quantiles (分位數) P10 / P50 / P90; the line is P50 and the band P10–P90. Needs at least 32 continuous readings; refreshed every few seconds on a GPU.

Accuracy metrics 評估指標

MAE   = mean |y − ŷ|                          same unit as the reading (平均絕對誤差)
RMSE  = √ mean (y − ŷ)²                       punishes big misses (均方根誤差)
sMAPE = mean 200·|y − ŷ| / (|y| + |ŷ|)  [%]   scale-free (對稱百分比誤差)
Skill = 1 − MAE_model / MAE_Persistence        > 0 % = better than “no change”

Step h: forecasts made h samples before the target. Avg: all steps 1…N. Same forecast times: every model is scored on the same (origin, step) pairs, so a model that started late is not judged on easier moments. Missing readings are never scored.

Alarm limits 警戒值

Empty = no limit on that side; limits stay on this phone until refresh. Rapid change (劇烈變化) = (max − min) of the next 10 forecasts ÷ |current value| ≥ 20%. Alerts use the models shown on the chart.
