Channel settings / 資料設定

Default 4 s = 0.25 Hz (phones could not keep up with 1 Hz). Fixed decimal places let a missed point be restored only when the image shows it. 固定小數位時，僅在影像確實看到小數點才會補回。Same item key + unit + interval → shared RNN/LSTM. Settings are fixed after creation.

手持補正以面板邊緣、標籤和按鍵追蹤，晃動時框會跟著面板移動；追蹤失敗會停收並記錄 TRACKING_ERROR，重新對準原面板即自動恢復。每次讀值先在框內找文字行，框稍有偏移也不會截斷數字。
