測試注意事項

1. Web NFC 通常需要 HTTPS、安全瀏覽環境，以及使用者按鈕觸發授權。

2. 本頁讀取的是 NDEF message；若 NTAG215 只有低階 memory pages 或 Amiibo 類資料，而非 NDEF text/URL record，瀏覽器不一定能讀取。

3. 若手機或瀏覽器不支援，請記錄手機型號、作業系統、瀏覽器版本與畫面錯誤訊息。
